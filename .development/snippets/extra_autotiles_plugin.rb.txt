#===============================================================================
# Extra Autotiles — дополнительные автотайлы сверх стандартного лимита в 7 слотов.
#===============================================================================
# Это НЕ сторонний "Unlimited Autotiles". Механизм встроен в Essentials v21
# (секция скрипта "TilemapRenderer", константа EXTRA_AUTOTILES). Здесь мы только
# наполняем её из плагина, чтобы не править основные скрипты.
#
#-------------------------------------------------------------------------------
# ФОРМАТ
#-------------------------------------------------------------------------------
#   tileset_id => [[большие автотайлы], [одиночные автотайлы]]
#
#   Большой автотайл   — файл 96x128 на кадр, 48 вариантов стыковки.
#                        Съедает 48 тайлов тайлсета. Пример: "Sea", "Sand shore".
#   Одиночный автотайл — файл 32x32 на кадр, 1 вариант.
#                        Съедает 1 тайл. Пример: "Flowers1", "Waterfall".
#
#   Оба массива обязательны, но любой может быть пустым: [[], ["Waterfall"]]
#   Анимация: N кадров = ширина файла N * 96 (или N * 32 для одиночных).
#   Скорость: суффикс в имени файла, "my_water[10].png" -> 10/20 = 0.5 с/кадр.
#            По умолчанию AUTOTILE_FRAME_DURATION = 5, т.е. 0.25 с/кадр.
#
#-------------------------------------------------------------------------------
# !!! ВАЖНО: КАКИЕ ТАЙЛЫ СЪЕДАЮТСЯ !!!
#-------------------------------------------------------------------------------
# Автотайлы отсюда подменяют тайлы С НАЧАЛА тайлсета (с ID 384), а не с конца.
# Порядок: сначала все большие, потом все одиночные.
#
# Для тайлсета 1 ("Outside", 8 тайлов в ряду) один большой автотайл занимает
# ID 384..431 — то есть ВЕРХНИЕ 6 РЯДОВ файла Graphics/Tilesets/Outside.png
# (пиксели y = 0..191).
#
# Эти 48 тайлов надо освободить под плейсхолдеры автотайла, иначе то, что было
# нарисовано там раньше, в игре превратится в воду.
#
# Плейсхолдеры раскладываются сеткой 8x6 — ровно так, как выглядит окно, которое
# открывается двойным кликом по настоящему автотайлу в RMXP.
#
# Проходимость (Passage), приоритет (Priority) и Terrain Tag берутся ИЗ ТАЙЛСЕТА
# по исходному ID тайла, а не из автотайла. Поэтому этим 48 плейсхолдерам надо
# в базе данных выставить Terrain Tag = Water и нужную проходимость.
#===============================================================================

TilemapRenderer::EXTRA_AUTOTILES.merge!(
  # Тайлсет 1 "Outside": одна анимированная вода как большой автотайл.
  # Занимает ID 384..431 = верхние 6 рядов Outside.png, куда вставлены
  # плейсхолдеры с 48 вариантами стыковки.
  #
  # Одиночные автотайлы идут ПОСЛЕ всех больших. Первый занял ID 432.
  # Угловые и изгибы — сюда: они кладутся руками, автостыковка им не нужна,
  # а стоят они 1 ID вместо 48.
  #
  # В полосе 18 рядов (144 тайла) сейчас занято 49. Свободно ID 433..527.
  1 => [["test_water_autotile"], ["test_water_autotile1"]]
)
